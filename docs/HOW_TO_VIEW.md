## 🐛 常见问题

### 页面不显示
1. 确认开发服务器正在运行
2. 检查浏览器控制台是否有错误
3. 尝试刷新页面 (F5)

### 样式显示异常
1. 清除浏览器缓存
2. 检查 `globals.css` 文件
3. 重启开发服务器

### 动画不工作
1. 检查浏览器是否支持 JavaScript
2. 查看浏览器控制台错误信息
3. 确认组件使用了 'use client' 指令
